# Project Glossary

## Core Concepts
- **App**: aplicación Android publicada para usuarios finales; no puede duplicarse en Projects.
- **Project**: repositorio público con ficha interna que no representa una App publicada.
- **fecha aproximada**: primer commit verificable mostrado expresamente como estimación histórica.
- **procedencia**: fuente, autor, licencia, estado de adaptación y razón de modificación de una skill.
- **skill adaptada**: skill que ArceApps modifica para sus flujos conservando sus obligaciones de origen.

## Relationships
- Un **Project** puede enlazar una **App** relacionada, pero no listarla como duplicado.
- La **procedencia** acompaña toda **skill adaptada**.
- La **fecha aproximada** solo se usa en Projects históricos; las publicaciones futuras usan fecha exacta.
