# Diseño de ejecución

La fuente visual es `DESIGN.md`; el modelo de Projects y SkillsAI está en `PROJECTS-DESIGN.md`.

La implementación reutilizará los tokens existentes, Inter para interfaz y Merriweather para lectura. El TOC pasa a una columna de 264–288 px solo cuando el contenedor de 1200 px puede reservar una lectura de 720–760 px; en los demás tamaños usa el desplegable de flujo normal.

Projects será una colección EN/ES tipada. La Home mezcla Apps y Projects por `pubDate` y muestra solo tres. SkillsAI se enlaza únicamente tras hacerse público y verificarse su procedencia.
