# Skill: OpenSEO Link Prospecting & Digital PR Técnico

## Objetivo y Contexto
Identificar sitios web de alta calidad, directorios técnicos, recopilatorios de recursos (*awesome lists*, blogs, newsletters) y autores que puedan referenciar o enlazar naturalmente a guías técnicas, herramientas o artículos de `arceapps.com`.

Combina las herramientas MCP de OpenSEO para el descubrimiento de páginas web que rankean con herramientas de búsqueda web para encontrar puntos de contacto públicos.

---

## 🛠️ Herramientas MCP y Búsqueda

- `get_serp_results`: Encuentra artículos recopilatorios, páginas de recursos (*curated lists*), comparativas y publicaciones de autoridad.
- `get_backlinks_overview`: Analiza qué dominios enlazan a competidores o a artículos similares del sector.
- `get_domain_overview`: Evalúa la autoridad y tráfico del sitio prospecto para priorizar el esfuerzo.
- `research_keywords`: Genera patrones de búsqueda de páginas de recursos (ej. `best astro tools`, `kotlin flow cheatsheet`, `indie developer resources`).

---

## 🔍 Patrones de Búsqueda de Prospectos Web

- `<tema> resources` / `<tema> curated list`
- `best <herramienta/librería> alternatives`
- `<tema> guide` / `<tema> deep dive`
- `awesome <tecnología>`
- `<tema> examples and tutorials`

---

## 🔄 Flujo de Trabajo

1. **Definir el Activo Enlazable:** Identificar la URL de ArceApps que aporta valor genuino (un artículo de 3000 palabras con benchmarks, un diagrama arquitectónico, una herramienta web).
2. **Generar Consultas de Prospección:** Lanzar búsquedas en Google vía `get_serp_results` para detectar páginas que recopilan herramientas o tutoriales de ese tema.
3. **Filtrar y Cualificar Prospectos:**
   - Priorizar páginas editoriales, blogs activos, documentación comunitaria y newsletters técnicas.
   - Descartar granjas de enlaces, sitios de spam o competidores comerciales directos que no admiten enlaces.
4. **Localizar el Canal de Contacto:** Buscar enlaces públicos (formulario de contacto, perfil en GitHub/X/LinkedIn, correo público en la web).
5. **Redactar Mensaje de Contacto Breve y de Alto Valor:**
   - Cero plantillas genéricas o correos masivos de spam.
   - Aportar valor directo (ej. alertar de un enlace roto en su lista, sugerir una ampliación con código abierto o nuevo benchmark).
